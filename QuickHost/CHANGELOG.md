# Changelog

## 0.0.1

- Initial release
- Auto-create lobby on game launch with configurable name, visibility, max players, and social tags
- `/quickhosttoggle` (`/qht`) - enable/disable auto-host for next launch
- `/quickhoststatus` (`/qhs`) - display current configuration
- `/quickhostrestart` (`/qhr`) - launch external restart script and quit
